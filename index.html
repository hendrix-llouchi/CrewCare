How the demo runs (2 minutes)

  1. One astronaut is amber — open them and see heart rate and sleep drifting from their own baseline.
  2. They get chest pain — run Emergency triage to the red outcome.
  3. Switch to Mars, send a message to Earth, watch the countdown. The app does not wait.
  4. Turn Wi-Fi off. Keep using the app.

About this app

CrewCare is an offline-first health companion for a Mars crew. All crew data is simulated and labelled. NASA Open Science Data Repository (OSDR) studies are used as evidence panels, not a live feed. Alert bands are team-defined demo values; the only published threshold is the SANS eye threshold (+20 / +55 micrometres).

Demo hosted on Vercel for judging. In flight, the same app runs on the spacecraft’s onboard computer — no cloud connection needed.
